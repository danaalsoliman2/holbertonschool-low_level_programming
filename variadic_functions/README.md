# C - Variadic functions

This project covers variadic functions in C using `va_list`, `va_start`, `va_arg`, and `va_end` from `<stdarg.h>`, as well as the `const` type qualifier.

## Files

- `variadic_functions.h`: Header file containing function prototypes and include guards.
- `0-sum_them_all.c`: Function that returns the sum of all its variable arguments.
